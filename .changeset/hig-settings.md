Settings now looks and behaves like a Mac settings window. It follows your accent color, and adding a VPN opens a sheet whose Add button turns on once the form is complete. Problems show under the field they're about as you type. Changes to a VPN stay put when you look at another pane, marked Edited until you Save or Revert. Optional fields sit under Advanced, and a missing tool shows up with an Install button where you pick the VPN type. You can drop a configuration file onto the editor, and Peony tells you when it can't read one.

A new Agents pane lets you turn agent control off, so `peony` answers "Agents can't control Peony right now" and exits 3. It also adds Peony to Claude Code, Codex or Cursor, or copies the command so you can run it yourself.
